# RF-ліфтинг

Односторінковий лендінг мікроголкового RF-ліфтингу на апараті Bionix Quantum.

Статичний сайт — один `index.html` з вбудованими стилями та скриптами, плюс зображення.

## Локальний запуск

```bash
python3 -m http.server 3847
```

Далі відкрити http://localhost:3847

## Деплой

Проєкт задеплоєний на Vercel: https://rf-lifting-landing.vercel.app/

## Акція

Дата завершення акції задана у двох місцях `index.html` — треба міняти обидва:

- текст банера «Пропозиція діє до …» (близько рядка 2015);
- ціль таймера зворотного відліку у функції `updateCountdown()` (близько рядка 2680), місяць вказується числом з нуля (`8` = вересень).
